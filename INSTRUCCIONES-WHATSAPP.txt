DENTAL SILOÉ — WHATSAPP

1. Abre src/pages/index.astro.
2. Al principio del archivo, cambia:
   const whatsappNumber = "";
   por el número oficial, por ejemplo: const whatsappNumber = "51XXXXXXXXX";
   (reemplaza las X por los nueve dígitos; no coloques el símbolo +, espacios o guiones).
3. Guarda, ejecuta npm run build y publica los cambios mediante GitHub/Netlify.

Al pulsar el icono verde, en celular se abrirá WhatsApp y en PC WhatsApp Web.
El mensaje prellenado es: Deseo agendar una cita
El usuario debe pulsar Enviar dentro de WhatsApp; el mensaje no se envía solo.

El resto de los ajustes de diseño corresponde a la versión V6 (header móvil, etc.).
